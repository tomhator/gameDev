# 뱀서 × 익스트랙션 (가칭) — 기획 및 스코프 문서

> 작성일: 2026-07-27
> 상태: 프리 프로덕션 (그레이박스 검증 전)
> 전작 교훈: 프로젝트 스캐빈저 — 익스트랙션 "장르"가 기획 전체를 잡아먹어 스코프 폭발로 보류.

## 한 줄 컨셉

버티기만 하던 뱀서류에 단 하나의 결정을 넣는다 —
**"이 전리품을 들고 지금 탈출할까, 욕심내다 다 잃을까."**

## 헌법 (제1원칙)

**익스트랙션은 장르가 아니라 규칙 하나다.**

게임의 몸통은 뱀서류(이동 + 자동공격 + 웨이브 + 레벨업 3택)가 지고,
익스트랙션이 기여하는 것은 아래 두 문장이 전부다:

1. **탈출 확정 규칙** — 런 중 드랍된 전리품은 탈출 지점까지 살아나가야만 내 것이 된다. 죽으면 전부 상실.
2. **무게 규칙** — 전리품을 주울수록 이동속도가 느려진다. (좋은 템일수록 무겁다)

### 수입 금지 목록 (익스트랙션 장르의 청구서 — 전부 거절)

- ❌ 인벤토리 관리 / 가방 테트리스
- ❌ 스태시(창고) 및 아이템 경제
- ❌ 장비 반입·손실 (타르코프 루프)
- ❌ 상인 NPC / 제작 시스템
- ❌ 맵 여러 개
- ❌ 스토리 / 퀘스트

### 리트머스 시험지

새 기능 아이디어가 떠오르면 반드시 묻는다:

> **"이게 없으면 '탈출 판단'이 재미없어지는가?"**

- 예 → 검토한다.
- 아니오 → 백로그(`BACKLOG.md`)에 적고 잊는다.
- "익스트랙션 게임이니까 필요하지"라는 논리가 나오면 → 스캐빈저의 유령. 즉시 기각.

## 코어 루프 (런 1회 = 5~8분)

```
진입 → 웨이브 시작 → 적 처치 / 레벨업 3택 → 전리품 드랍
  → [결정] 줍는다(무거워짐) / 버린다(가벼움 유지)
  → 시간이 갈수록: 보상↑ 웨이브 강도↑
  → [결정] 탈출 지점으로 이탈(전리품 확정) / 더 버틴다(더 큰 보상, 더 큰 위험)
  → 탈출 성공: 전리품 → 메타 재화  |  사망: 전부 상실
```

### 메타 진행 (블랙홀 키우기의 임계점 쾌감)

- 가져온 재화로 **운반 용량**(무게 페널티 완화)을 키운다.
- 용량이 커지면 → 더 무거운(비싼) 전리품을 노릴 수 있다 → 더 깊은 욕심 → 더 큰 긴장. 성장이 긴장을 재충전하는 순환.
- 그 외 메타 업그레이드는 소수(시작 무기 해금, 체력 등 5~8종 이내).

## 스코프 상한 (출시 전 절대 불가침)

| 항목 | 상한 |
|---|---|
| 맵 | **1개** |
| 무기 | **5~6종** |
| 적 | **4종** (일반 3 + 엘리트/보스 1) |
| 패시브/강화 | 8~10종 |
| 메타 업그레이드 | 5~8종 |
| 런 길이 | 5~8분 |

상한을 넘는 콘텐츠 아이디어는 전부 출시 후 업데이트 소재다.

## 전작 부검 → 이번 대응

| 스캐빈저의 발목 | 원인 진단 | 이번 프로젝트의 방어책 |
|---|---|---|
| 1. 콘텐츠만 불어남 ("익스트랙션이라면~" 논리로 무기/템 추가) | 장르가 청구서를 냄 | 헌법·수입 금지 목록·리트머스 시험지·스코프 상한 |
| 2. 세계관(아포칼립스/정크펑크/SF)에 맞는 에셋이 없음 | 에셋 시장이 얇은 테마를 먼저 정함 | **테마를 에셋 시장에서 고른다** (아래 참조) |
| 3. 아트 결과물 불만족 → 남은 아트 작업량에 압도 → 의욕 상실 | 직접 제작 물량이 크리티컬 패스에 올라옴 | 팩 1개 통일 + 일관성 우선 + 자체 제작 최소화 |

## 테마: 판타지 던전 도굴꾼 (에셋 우선 테마 선정)

**원칙: 테마에 맞는 에셋을 찾지 말고, 에셋이 넘치는 테마를 고른다.**

> "던전에 숨어든 도굴꾼. 보물을 쓸어 담을수록 몸은 무거워지고,
> 던전은 침입자를 조여온다. 살아서 나가야만 내 것이다."

- 익스트랙션 서사(잠입→약탈→탈출)가 그대로 성립하면서, 픽셀 에셋 공급이 가장 두꺼운 테마.
- 후보 팩: 0x72 Dungeon Tileset II (무료), Kenney Tiny Dungeon 등. **1~2주차에 팩 1개를 확정**한다.
- 정크펑크/아포칼립스 세계관은 폐기가 아니라 보류 — 차기작 또는 출시 후 스킨 소재.

## 아트 방침 (전작 병목 대응)

- **선정한 팩 하나만 끝까지 쓴다. 팩을 섞지 않는다.** 체감 퀄리티는 개별 그림이 아니라 일관성에서 나온다.
- 자체 제작(그리기/AI)은 아이콘 등 소품 몇 개 이하로 제한. 커스텀 아트는 **마지막 2주에만**, 교체가 쉬운 것부터.
- 아트는 크리티컬 패스에서 제외한다 — 아트가 늦어져도 출시는 늦어지지 않는 구조.

## 마일스톤 (주 15~20시간 기준, 총 8~10주)

| 주차 | 목표 | 완료 기준 |
|---|---|---|
| 1~2 | **그레이박스 코어 루프** | 도형만으로 이동/자동공격/웨이브/드랍/무게/탈출/사망상실이 전부 도는 빌드. 에셋 팩 1개 확정. **Go/No-Go: 탈출 판단이 실제로 쫄깃한가?** |
| 3~4 | 콘텐츠 골격 | 무기 5~6종, 적 4종, 레벨업 3택, 전리품 테이블 |
| 5~6 | 메타 진행 + 밸런스 | 용량 성장 순환 작동, 런 5~8분 안착, 난이도 곡선 1차 |
| 7~8 | 폴리싱 | 에셋 교체, 사운드, 타격감, 타이틀/게임오버/메타 화면 |
| 9~10 | 버퍼 + 출시 | 버그픽스, itch.io 업로드. **"못생겨도 출시"가 목표.** |

## 그레이박스에서 검증할 설계 질문 (2주차 말까지 결정)

1. 탈출 지점은 **상시 개방**인가, **주기적 개방**(예: 2분마다 15초)인가?
   - 상시: 판단이 자유롭지만 긴장 밀도가 낮을 수 있음 / 주기: "이번 차를 탈까 다음 차를 노릴까"라는 결정 리듬이 생김. → 그레이박스에서 둘 다 시험.
2. 무게 페널티 곡선 — 선형 감속 vs 구간별 임계점(가벼움/보통/과적). 임계점 방식이 결정을 더 또렷하게 만들 가능성.
3. 사망 시 상실 범위 — 전부 상실(순수) vs 소액 보존(좌절 완화). 우선 전부 상실로 시작, 플레이테스트로 판단.

## 이 문서의 용도

- 작업 중 방향이 흔들릴 때 돌아오는 기준점.
- 특히 **수입 금지 목록**과 **리트머스 시험지**는 매주 스코프 점검 시 다시 읽을 것.
