# drill-guard (가칭) — 기획 및 스코프 문서

> 작성일: 2026-08-10
> 상태: 그레이박스 1주차 착수 (`/drill-guard`)
> 전작 교훈: project-jigsaw — 보드 위 시너지는 조합 폭발로 사망. 시너지는 수식에만 붙인다.
> 관련 문서: `survivor-extraction-plan.md`의 "철수 판단" 규칙은 검토 후 **의도적 미채용** (아래 수입 금지 참조).

## 한 줄 컨셉

**식민 행성에 채굴 드릴을 파견한다. 배터리가 다할 때까지, 용병과 커서로 지켜낸다.**
인크리멘탈 × 디펜스 — 커서 반경은 자동 공격이라, 유저의 유일한 실시간 판단은 "지금 어디가 제일 급한가".

> "커서가 닿는 곳은 불바다가 된다.
> 커서가 닿지 않는 곳은 — 용병을 믿어야지."

## 헌법 (제1원칙)

**이 게임은 시스템이 아니라 규칙 4개다.**

1. **드릴 = 지킬 것 = 돈줄 = 시계.** 드릴이 사는 동안 광물이 쌓이고, 배터리가 다하면 파견 종료. 드릴이 터져도 **캔 만큼은 회수한다** (좌절 방지 — 모든 런이 전진).
2. **커서 반경 자동 공격.** 클릭도 드래그도 없다. 커서의 위치가 곧 화력 배분 — 주의력이 곧 무기다.
3. **용병은 자동 전투.** 파견 전에 배치하고, 전사하면 재배치 버튼(딜레이 후)으로 다시 투입. 배치의 의미 = "커서가 못 보는 방향을 맡기는 일".
4. **성장은 런 사이 영구 수식 업그레이드뿐.** 드릴/배터리/커서/용병의 숫자만 자란다. 런 중 성장 없음.

**다섯째 규칙은 없다.**

### 수입 금지 목록 (전부 거절)

- ❌ 보드/배치 시너지 ("A 옆에 B면 버프") — **project-jigsaw의 유령. 즉시 기각**
- ❌ 방치/오프라인 수익 — 인크리멘탈 ≠ 방치. 이 게임의 코어는 실시간 커서 판단이다
- ❌ 런 중 상점·레벨업·성장 — 성장은 본부(런 사이)에서만
- ❌ 철수 판단·전리품 상실 (익스트랙션 규칙) — 배터리 고정 시간이 이 게임의 답
- ❌ 커서 클릭/드래그/스킬 조작 — 위치가 전부 (콘텐츠 확장 카드로 백로그 보존)
- ❌ 스토리, 퀘스트, 허브 탐험, 맵 여러 종

### 리트머스 시험지

> **"이게 없으면 '커서를 어디 둘까'가 재미없어지는가?"**

아니오 → `drill-guard/BACKLOG.md`에 적고 잊는다(48시간 룰).
"인크리멘탈이라면/디펜스라면 ~가 필요하지" → 장르의 청구서. 즉시 기각.

## 코어 루프

```
파견 준비: 용병 배치(클릭) → 파견 시작
  → 드릴 가동: 초당 광물 채굴, 배터리 카운트다운(기본 30초)
  → 적 웨이브: 시간이 갈수록 가속 — 용병 자동 전투 + 커서 반경 자동 공격
  → 용병 전사 시: 딜레이 후 재배치 버튼으로 재투입
  → 배터리 소진(성공) 또는 드릴 파괴(실패) — 어느 쪽이든 채굴량 회수
  → 본부: 광물로 영구 업그레이드(드릴/배터리/커서/용병) → 재파견
```

| 항목 | 결정 |
|---|---|
| 드릴 파괴 시 채굴량 | **유지** (전량 회수) |
| 기본 배터리 | **30초** — 그레이박스에서 체감 튜닝 |
| 커서 : 용병 화력 비율 | 그레이박스에서 튜닝 (아래 검증 질문 ①) |
| 용병 배치 | 런 시작 전 배치, 전사 시 **재배치 버튼**으로 재투입 (복귀 딜레이 있음) |
| 방치 요소 | 없음 (확정) |

### 성장 축 (전부 수식 — 상한 8개 내외)

채굴 속도 · 배터리 용량(+5s: **런 길이 자체가 성장**) · 드릴 장갑 · 커서 화력 · 커서 반경 · 용병 화력 · 용병 체력 · 용병 수(+1)

## 그레이박스 검증 질문 (Go/No-Go — 플레이로만 답한다)

1. **커서 : 용병 비율** — 커서가 너무 세면 배치가 무의미해지고, 용병이 너무 세면 손이 심심하다. "커서는 한 방향만 감당 가능, 나머지는 용병 몫"이 나오는 수치를 찾는다.
2. **배터리 30초** — 한 런이 "한 판 더"를 부르는 길이인가? 너무 짧아 업그레이드 화면만 보는 게임이 되진 않나.
3. **재배치의 긴장** — 용병 전사 → 복귀 딜레이 → 어디에 다시 꽂을까. 이 순간이 위기 대응의 재미가 되는가.
4. **주의력 배분이 재미인가** — 커서를 옮기는 것"만"으로 30초가 바쁘고 즐거운가. 이게 아니오면 게임 전체가 아니오다.
