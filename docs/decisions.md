# 결정 로그

대화 원문은 남기지 않는다. 남기는 것은 **맥락 → 근거 → 결과** 세 줄이다.
새 항목은 **맨 위에** 붙인다. 지난 항목은 고치지 않는다 — 뒤집혔으면 새 항목에 "앞 항목을 뒤집음"이라고 적는다.
규칙은 CLAUDE.md 규약의 "결정 로그" 절. 티켓 안에서 끝난 결정은 티켓 댓글이 원본이고, 여기엔 세 줄 + `#번호`만 둔다.

```
## YYYY-MM-DD · 제목 (#티켓)
- 맥락: 무엇을 하다가 이 판단이 필요해졌나
- 근거: 무엇을 보고 그렇게 정했나 (버린 대안 포함)
- 결과: 무엇이 달라졌나 / 다음에 무엇을 하나
```

## 2026-09-11 · 첫 쁘띠 사이클 소재 = 처마 투 처마 (#21 → #37)
- 맥락: 새 쁘띠 프로젝트 아이디어 회의. Claude가 낸 후보 5개(#21: 등 뒤로·jigsaw-snap·뒷골목·저승 배달부·drill-guard S2)가 결정권자에게 "썩 별로".
- 근거: "게임은 현실의 추상화" 프레임으로 다시 — 추상화할 것은 직업·장소가 아니라 그 순간의 결정과 기분. 결정권자가 현실의 순간 둘(처마 사이 달리기, 엘리베이터 열림/닫힘)을 기이현상으로 비틀었다. 처마는 재미가 규칙 하나 + 튠에 있어 무음으로도 검증되고 더 독창적. 엘리베이터는 검증된 장르(8번 출구·That's Not My Neighbor류)라 사운드·이상현상 콘텐츠가 필요해 2번째 사이클 후보로 보관. 결정권자 취향 신호: 일상 + 기이현상(뒷골목 늑대개도 같은 결).
- 결과: #37 `idea`. 원안(즉시 되돌림 / 스탯 업그레이드) vs Claude 제안(연속 되감기 / 판단형 샤드 3개)은 토이에서 둘 다 켜고 끌 수 있게 만들어 S2 플레이가 정한다. 저장소 위치·4조 충돌(drill-guard·football-xcom 보류)·S2 날짜는 #37에서 결정권자가 답한다.

## 2026-09-10 · 대화 맥락은 원문이 아니라 세 줄로 남긴다 (#31)
- 맥락: 티켓 댓글 밖(터미널·클로드 앱 세션)에서 오간 논의를 어떻게 관리하느냐는 질문. 지금 규약이 붙잡는 채널은 티켓 댓글과 STATUS.md 둘뿐이고, 세션 대화는 끝나면 사라진다.
- 근거: 원문 transcript를 쌓으면 다음 세션이 읽을 양이 통제 불능이 되고, 로컬 memory는 환경마다 있고 없어서(Action 세션엔 없다) 진실의 소스로 못 쓴다. 필요한 건 "왜 그렇게 됐나"이지 대화 자체가 아니다. STATUS.md는 덮어쓰는 인수인계 메모라 누적 기록으로 부적합.
- 결과: `docs/decisions.md` 신설 — 맥락→근거→결과 세 줄을 맨 위에 append. 세션 시작에 최근 10개를 읽고 세션 끝에 적는다. 규약에 "결정 로그" 절 추가.
