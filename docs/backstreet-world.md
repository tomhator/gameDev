# 뒷골목(Backstreet) — 세계관 컨셉 회수

> 출처: `tomhator/BackstreetSample` (2026-07-07~08, 커밋 2개, `Main.gd` 295줄). 문서 파일은 없었고 전부 코드의 주석·문자열·변수명에서 회수했다. 코드 헤더 스스로 "throwaway code"라 선언했으므로 코드는 버리고 **컨셉만 여기 남긴다.**
> 확정된 사실과 추정을 구분했다. "(추정)"이 붙은 것은 코드에 근거는 있지만 개발자가 적어 둔 결정은 아니다.

## 한 줄

**심야 편의점 뒷골목에서 벌어진 "사건 #001"을, 인간과 늑대개 두 몸을 바꿔 가며 조사하는 탑다운 탐정 게임.**

## 확정된 것

### 배경
- 현대 한국 도시의 밤. 편의점, CCTV, 알바생, 폐기 선반이 등장한다.
- 시간대는 심야. 단서 문구에 "새벽 2시경"이 있다.
- 색은 전부 어두운 회청·갈색 계열. 월드 배경 `(0.12, 0.12, 0.14)`. 네 존 중 "옆 가게 앞"만 따뜻한 갈색이다.
- 제목: **Backstreet - Case #001**. 사건 번호를 붙인 것으로 보아 에피소드 단위 구조를 염두에 둔 듯하다(추정).

### 주인공 — 인간 ↔ 늑대개
| | 인간 | 늑대개 |
|---|---|---|
| 전환 | Tab | Tab |
| 이동 속도 | 200 | **300 (1.5배)** |
| 표시색 | 파랑 | 오렌지 |
| 화면 | 원색 | 전체가 어두운 청록 톤으로 물듦 (`CanvasModulate`) |
| NPC 대화 | 가능 | **불가** (`human_only` 플래그) |
| 조사물(선반·CCTV) | 가능 | 가능 |

핵심 규칙은 하나다. **사람은 말로 조사하고, 늑대개는 몸으로 조사한다.** 늑대개 전용 단서(냄새 등)는 미구현이지만 `human_only` 플래그의 대칭으로 `wolfdog_only`가 예정돼 있었다고 보는 게 자연스럽다(추정).

### 사건 #001
회수된 단서는 두 개다.
- 폐기 선반: **"작은 손톱 긁힌 자국"**
- CCTV 모니터: **"새벽 2시경 화면 노이즈, 인물 미검출"**

사건의 정체(도난, 실종, 습격)는 코드에 없다. 폐기 식품 선반에 작은 손톱 자국, CCTV에 사람은 없고 노이즈만. **작은 비인간 존재가 폐기 음식을 노렸고, 카메라에 잡히지 않는다**는 방향이 읽힌다(추정). 주인공 자신이 늑대개로 변하는 존재라는 점과 맞물리면, 범인도 같은 부류일 가능성이 이 사건의 훅이다(추정).

### 존 4곳
| 존 | 화면 위치 | 톤 | 안에 있는 것 |
|---|---|---|---|
| 편의점 내부 | 좌상 | 회청 | 시작 지점. 알바생, 폐기 선반, CCTV 모니터 |
| 편의점 뒤 골목 | 좌하 | 어두운 청회 | 없음 (미구현) |
| 옆 가게 앞 | 우상 | 갈색 (유일한 따뜻한 톤) | 할머니 |
| 막다른 골목 (뒷골목 입구) | 우하 | 가장 어두움 | 없음. 제목의 "뒷골목"으로 이어지는 관문(추정) |

### 등장인물
- **알바생** — 편의점 내부. 대사 플레이스홀더: "어서오세요~ (대화는 3단계에서)"
- **할머니** — 옆 가게 앞. 대사 플레이스홀더: "응? (대화는 3단계에서)"

### 단서 시스템(구현된 대로)
- 반경 62 안 가장 가까운 대상에 `[Space] {이름} 대화/조사` 프롬프트.
- 획득 시 상단 토스트 "단서 획득: …" 2초 후 페이드. 중복이면 "이미 확보한 단서".
- J 키로 우측 단서 목록 패널. 비었으면 "(아직 없음)".
- 단서는 `id → text` 딕셔너리. 발견 조건은 접근 + Space만, 모드 조건 없음.

## 톤·레퍼런스 (추정)
한국 심야 편의점 괴담 × 도시 미스터리. 소형 사건 단위 탐정물이고, 인간/동물 전환은 『Blacksad』(동물 탐정 누아르)나 『Okami』의 감각 모드에 가깝다. 코드에 명시된 레퍼런스는 없다.

## 다시 쓸 때 메카닉 메모
- **모드 토글로 상호작용 집합이 바뀌는 구조**가 이 컨셉의 엔진이다. 같은 장소를 두 몸으로 두 번 훑는 것이 탐정 루프가 된다. `human_only` / `wolfdog_only` 두 플래그와, 한 단서를 모드별 다른 텍스트로 얻는 확장이 자연스럽다.
- 모드 전환 = **화면 톤 + 이동 속도 + 대화 가능 여부** 세 가지를 한 함수에서 바꾸는 것만으로 체감 차이가 났다. `CanvasModulate` 하나로 "감각 모드" 연출이 된다.
- 씬 파일 없이 전부 코드로(ColorRect + Label) 만들어 하루 1스테이지씩 나간 방식이 그레이박스에 잘 맞았다.
- 미완 항목: 3단계 대화, 뒷골목·막다른 골목의 조사물, 늑대개 전용 단서, 사건 결론·추리 단계.
