# jigsaw-snap — 직소 "착!" 손맛 아이디어 보관

> 2026-09-10 종료(#19). 코드는 이 저장소 커밋 `0fd191b` 이전의 `jigsaw-snap/`에 있다(복구: `git checkout 0fd191b -- jigsaw-snap`).
> 결정권자 판단: **"아이디어 자체는 좋은 것 같은데 아직 게임의 방향을 못 잡겠다."** 그래서 게임이 아니라 아이디어로 보관한다.
> 전작 project-jigsaw(2026-04)의 교훈이 이 토이의 전제였다: 조각에 타입·시너지를 붙이는 순간 조합 폭발. 손맛만 먼저.

## 검증하려던 것 (답 없음 — 아무도 플레이하지 않았다)
1. 연달아 끼울수록 세지는 "착!" 콤보 에스컬레이션이 실제로 기분 좋은가
2. 3초 콤보 타이머가 쫄깃한가 짜증나는가 (젠 모드와 비교)
3. 들어갈 자리를 눈으로 수색하는 순간이 재미인가 스트레스인가

## 규칙 (그레이박스에 구현된 것)
| 요소 | 값 |
|---|---|
| 보드 | 7×7, 중앙 핵 1칸 |
| 조각 | 4변 각각 돌기 +1 / 홈 −1 / 평평 0. 인접 변의 **합이 0이면 맞물림** |
| 조작 | 배치 · 회전 · 버리기(콤보 리셋) · 대기열 4 |
| 콤보 | 3초 윈도우 안에 연속 배치 시 +1. 젠 모드는 타이머 없음 |
| 점수 | 10 × 맞물린 변 수 × 콤보 |
| 만끼움 | 4변 전부 맞물림 → 히트스톱 보너스 |
| 연출 | snap SFX는 콤보에 따라 pitch 상승(런타임 합성, 에셋 0). Juice(셰이크·팝업·파편·히트스톱) |
| 튜닝 후보 | 콤보 윈도우 2~4s, 변 분포 0.4/0.4/0.2, 팝·셰이크 강도 |

## 이 손맛 위에 얹을 게임 후보 (미정, 전부 논의 중)
- **웨이브 = 블라인드**: 발라트로식 점수 목표를 디펜스 껍데기로. 적은 시뮬레이션이 아니라 위협 수치
- **성벽 디펜스**: 틈으로 침투·벽 갉기. "완봉되면 끝" 문제의 해법 후보: 총안 / 숨구멍 / 킬 경제 / 조각 도둑 / 공중 적 / 보드 확장 / 가두기(목표 역전)
- **디제틱 타이머**: 카운트다운 대신 걸어오는 적이 곧 시계
- 점수 정산 시점: 끼울 때마다 즉시 vs 라운드 말 연쇄 정산

## 손맛 쪽 추가 실험 후보
- 억지로 끼우기: 안 맞는 조각 강제 배치 = 금 감(HP/점수 페널티)
- 콤보 정점 연출: 고콤보에서 화면 연출 단계 상승
- 조각 변 분포를 판마다 바꿔 "기근 판/풍년 판" 체감 비교

## 다시 열 때
1. 먼저 10분 플레이해서 위 검증 질문 3개에 답을 적는다. 답 없이 방향 회의 금지.
2. 방향 후보는 `knowhow.md` §1-1(조합 폭발)과 §2-1(단위 개체 태그 ≤1, 위상 시너지 금지)을 통과해야 한다.
3. 쁘띠 게임 사이클(3~7일, 공개 URL이 완료)에 맞는 크기로만 연다.
