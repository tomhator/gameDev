# 직소 디펜스 (가칭) — 기획 및 스코프 문서

> 작성일: 2026-08-10
> 상태: 아이디어 확정 (그레이박스 착수 전) — helldiver-lite 진행 중이므로 착수 시점은 별도 판단
> 전작 교훈: project-jigsaw — 조각에 타입/소켓/시너지를 붙이자 조합 폭발로 시스템이 불어나 폐기.

## 한 줄 컨셉

**벽을 완성하는 게임이 아니라, 필터를 설계하는 게임.**
직소 조각을 끼워 성벽을 쌓고 코어를 지킨다 — 적은 틈으로 스며들지만, 나도 틈으로만 쏠 수 있다.

> "운 나쁘게 안 맞는 조각만 손에 들어왔다. 구멍을 어디에 남길 것인가 —
> 아니, 어떤 모양의 구멍을 남겨서 놈들을 갈아버릴 것인가."

## 그림 배제 선언

**이 게임에 그림은 없다. 하얀 퍼즐이다.**
직소에서 가져오는 것은 세 가지뿐: **돌기/홈의 맞물림, 틈, 끼울 때의 "착" 하는 촉감.**
그림 완성·세트 보너스·명화 감상은 전부 버린다. 직소의 게임적 재미는 모양 싸움에 있다.

## 헌법 (제1원칙)

**직소 디펜스는 시스템이 아니라 규칙 4개다.**

1. **조각 = HP 덩어리.** 1칸짜리, 4변이 돌기(+)/홈(−)/평평(0). 능력도 타입도 시너지도 없다.
2. **맞아야 끼워진다. 안 맞으면 억지로 끼운다.** 돌기는 홈에만 맞물린다. 안 맞는 조각을 우겨넣을 수는 있지만 금이 가서 HP 절반.
3. **적은 틈으로 침투하고, 막히면 벽을 갉는다.** 바깥과 이어진 빈칸이 침투 경로. 갉는 힘은 웨이브마다 세진다 — 완봉은 승리가 아니라 잠깐 벌어둔 시간이다.
4. **코어는 틈으로만 자동 사격한다 (총안).** 4면 완봉 = 안전하지만 무득점. 적은 바깥에 쌓이며 다음 웨이브와 합쳐진다. 최적해는 완봉이 아니라 킬존이다.

규칙 1~2가 직소를, 규칙 3~4가 디펜스를 담당한다. **다섯째 규칙은 없다.**

### 수입 금지 목록 (project-jigsaw를 죽인 청구서 — 전부 거절)

- ❌ 조각 타입/속성 (화염 돌기, 기름 홈 등)
- ❌ 소켓 시너지, 에너지 흐름, 회로/루프 보너스
- ❌ 조각 능력, 유물, 특수 조각
- ❌ 그림, 세트 보너스, 영역 완성 보상
- ❌ 상점, 골드, 경제 (조각 수급은 라운드마다 무상 랜덤 N개가 전부)
- ❌ 폴리오미노(다칸) 조각 — 조각은 영원히 1칸
- ❌ 타워 여러 종 — 쏘는 것은 코어 하나뿐

### 리트머스 시험지

> **"이게 없으면 '틈 설계'가 재미없어지는가?"**

아니오 → `BACKLOG.md`에 적고 잊는다(48시간 룰).
"디펜스라면 타워가/업그레이드가 필요하지"라는 문장이 나오면 → 장르의 청구서. 즉시 기각.
"조각에 효과를 하나만 붙이면…"이라는 문장이 나오면 → **project-jigsaw의 유령. 즉시 기각.**

## 코어 루프 (런 1회 = 8~12분, 검증 대상)

```
라운드 시작: 랜덤 조각 N개 수급 (돌기/홈 배열 랜덤, 회전 가능)
  → [배치] 맞는 자리에 끼운다 / 억지로 끼운다(HP 절반) / 버린다
  → [설계 판단] 구멍을 어디에, 어떤 모양으로 남길 것인가 (킬존)
  → 웨이브 자동 전투: 적은 틈으로 침투·벽을 갉고, 코어는 틈으로 사격
  → 부서진 조각은 빠진다 — 구멍의 모양은 이웃 조각의 돌기/홈이 결정
  → 다음 라운드 (적 갉는 힘 증가)
최종 웨이브 생존 = 승리  |  코어 파괴 = 런 종료
```

배치가 플레이어의 전부, 전투는 전부 자동. 전투 중 조작 없음 — 오토배틀러의 관전 긴장을 가져온다.

## 스코프 상한 (출시 전 절대 불가침)

| 항목 | 상한 |
|---|---|
| 보드 | **1종** (예: 9×9 프레임 + 중앙 코어 1) |
| 조각 종류 | **1종** (변형은 돌기/홈 배열 랜덤이 담당 — 콘텐츠 비용 0) |
| 적 | **3종** (침투형 / 갉는형 / 대형 1) |
| 웨이브 | 10 (런 8~12분) |
| 메타 진행 | 해금 5종 이내 (그레이박스 검증 후에만 착수) |
| 조작 | 드래그 배치 + 회전 + 억지 끼우기. 전투 중 조작 없음 |

## 전작 부검 → 이번 대응

| project-jigsaw의 발목 | 원인 진단 | 이번 방어책 |
|---|---|---|
| 조각 타입·소켓 시너지의 조합 폭발 | 복잡도를 조각 **내부**에 넣음 | 복잡도를 조각 **외곽선**에만 둔다 — 조각은 변 4개 값 + HP가 전부 |
| 시스템이 불어나며 밸런싱 불능 | 시너지는 곱셈으로 불어남 | 튜닝 대상은 숫자 몇 개뿐: 조각 변 분포, 갉기 곡선, 총안 화력, 금 페널티 |
| "직소다움"을 시너지로 구현하려 함 | 그림·연결에 의미를 부여 | 직소다움 = 모양이 안 맞는 데서 오는 긴장 + 끼우는 촉감. 그게 전부다 |

## 아트 방침

- **하얀 퍼즐이 곧 아트 방향이다.** 조각은 도형에 가깝게 — 에셋 수요가 거의 없는 드문 기획.
- 대신 **촉감에 몰빵**: 스냅 애니메이션, "착" 사운드, 금 가는 이펙트, 조각이 빠질 때의 파열감. 폴리싱 예산은 전부 여기로.
- 테마(성벽/얼음/쿠키 등)는 출시 후 스킨 소재. 크리티컬 패스 제외.
- 스캐빈저 인양물 적용: Juice.gd(손맛 유틸), 텔레그래프 문법(갉히는 조각 점멸), float HP.

## 그레이박스 1주차 범위 (도형만으로 전부)

- 격자 + 중앙 코어, 조각 생성(4변 ±1/0 랜덤), 드래그 배치 + 회전, 맞물림 판정
- 억지 끼우기(HP 절반 + 시각 표시)
- 바깥 연결 빈칸 계산(flood fill) — 침투 경로와 총안이 같은 데이터를 쓴다
- 적 침투(빈칸을 타고 코어로), 벽 갉기, 총안 틱 데미지, 웨이브 10회, 승패 판정

## 그레이박스 검증 질문 (Go/No-Go — 플레이로만 답한다)

1. **긴장의 원천이 성립하나** — 랜덤 돌기/홈 분포만으로 "아 이 자리 조각이 안 나오네"가 매 라운드 생기는가? 분포 튜닝(평평 비율)으로 조절.
2. **완봉 vs 킬존이 실제로 갈리나** — 총안 화력·갉기 곡선 수치에서 완봉 시도가 자연히 손해가 되는가? 완봉이 여전히 최적이면 규칙 4의 수치 재조정.
3. **억지 끼우기를 실제로 쓰게 되나** — HP 절반이 "쓸 만하지만 아픈" 지점인가? 안 쓰면 페널티 완화, 남발하면 강화.
4. **관전 구간이 지루하지 않나** — 웨이브 1회 전투 길이의 상한은? (배치 시간 대비 전투 시간 비율 검증)
