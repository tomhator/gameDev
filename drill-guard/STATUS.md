## 현재 초점

> 🎯 **2주차 Go/No-Go: "커서를 어디 둘까"라는 주의력 배분이 그 자체로 재밌는가?**
> 스코프 헌법·수입 금지 목록은 `../docs/drill-guard-plan.md` — 흔들릴 때마다 그 문서로.

- **구현 상태 (그레이박스, 도형만):** 파견 준비(용병 클릭 배치) → 방어(배터리 30초 카운트다운 = 드릴 둘레 링, 초당 채굴, 적 웨이브 가속, 용병 자동 사격 + 커서 반경 자동 공격) → 종료(배터리 소진/드릴 파괴 — **어느 쪽이든 채굴량 회수**) → 업그레이드 상점(8축 수식) → 재파견의 **풀 루프 작동.** 용병 전사 → 2초 후 예비 복귀 → 재배치 버튼(B). 영구 저장(user:// ConfigFile). 합성 SFX(에셋 0개, jigsaw-snap 인양), Juice 인양(셰이크/팝업/파편). 엔진 = Godot 4.7, 640×360 정수배.
- **미검증 = 실제 플레이 손맛.** 아직 아무도 플레이 안 함. 특히 커서:용병 화력 비율(현재 커서 8dps vs 용병 6dps/기)은 순수 추정치.

## 조작

클릭 = 용병 배치(준비/재배치 모드) · Enter = 파견 시작/재파견 · B 또는 버튼 = 재배치 모드 · 마우스 이동 = 커서 오라(자동 공격)
